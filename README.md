# 神兽志 (Mythical Bestiary)

一款聚焦全球神话生物的图鉴类工具 App，面向奇幻游戏玩家、神话爱好者、DND/TRPG 玩家等用户群体。

## 项目特点

- **纯离线应用**：无需联网，所有数据本地存储
- **5大文化体系**：中国、希腊、北欧、日本、印度
- **20位神祇图鉴**：各大文明的至高主神与神话故事
- **140+神话生物**：详细的神兽图鉴和神话传说
- **7种元素属性**：火、水、风、雷、光、暗、自然
- **沉浸式设计**：深色主题，AI生成精美图片

## 功能模块

### 1. 首页发现

- 网格/列表双模式展示
- 详细的神兽信息页面

### 4. 神话百科
- 神祇图鉴入口（新增）
- 7种元素属性详解
- 7种文化体系介绍
- 能力词典

### 5. 个人中心
- 收藏管理
- 浏览历史
- 设置

### 6. 互动娱乐
- 每日占卜
- 属性测试

### 7. 专题文章
- 神话主题深度解读

## 技术架构

- **平台**：HarmonyOS
- **开发语言**：ArkTS
- **UI框架**：ArkUI
- **数据存储**：
  - JSON文件（rawfile）
  - Preferences（用户数据）

## 项目结构

```
entry/src/main/
├── ets/
│   ├── common/          # 常量和主题
│   ├── components/      # 可复用组件
│   ├── model/           # 数据模型
│   ├── pages/           # 页面
│   └── utils/           # 工具类
└── resources/
    ├── base/media/      # 图片和图标资源
    └── rawfile/data/    # JSON数据文件
```

## 开发命令

```bash
# 编译项目
hvigorw assembleHap

# 运行到模拟器
hvigorw installHapDebug

# 清理构建
hvigorw clean
```

## 开发约束

1. 图片资源必须放在 `base/media/` 目录（不可嵌套）
2. 禁止使用网络图片
3. 禁止使用 emoji，必须用 SVG 图标
4. 每完成功能需运行编译检查
