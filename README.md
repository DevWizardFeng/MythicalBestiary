我现在要开发的是一个鸿蒙的 App 

你需要阅读 神话生物图鉴-PRD.md 来理解我的开发需求

harmonyos_docs 是整个鸿蒙的开发约束文档你在编写任何代码之前都需要查询 文档索引.md

你要根据文档来开发！严格语法约束不可以自己瞎写代码要严格按照约束来！

每完成一个功能你就需要运行、 hvigorw assembleHap 、使用 bash -C 来运行！必须要确保编译没有任何错误！

不可以使用线上图片我纯单机应用不需要联网的

鸿蒙的图片是不允许文件夹嵌套的必须都在同一层！必须全部放在 base/media 目录下！

不可以使用 emoji 用到的所有图标你必须生成 SVG 文件放到 base/media

example.py 是 AI 生图的模板的示例你按照这个重新创建 py 脚本但是 baseURL apikey 请求模型不可改变

我需要确保每个类目至少20张图片！

我希望页面是沉浸式的用到的背景图片或者漆扇图片之类的全部使用 AI 生成！我已经写好了脚本你只需要稍微改造我的脚本即可
